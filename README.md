## Core systems / Temel sistemler

| | |
|---|---|
| The Felt / Çuha | 5-lane tactical board: front/back rows + mantel, face-down (concealed) placement, reveals and clashes |
| Soul Chips / Ruh Çipi | Unified life = mana = stake |
| The Pot / Pot | All chip damage antes into a shared prize the winner claims |
| The Blinds / Perdeler | Escalating ante — every battle self-terminates |
| Devil's Credit / Şeytan Kredisi | Borrow power now, pay with interest — debt shapes the run |
| Seals / Mühürler | Modular graftable abilities, each with a named counter |
